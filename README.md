# SDR.NET

Набор библиотек для программной обработки цифровых радиосигналов по технологии SDR
на платформе .NET. Целевая платформа — .NET 10. Библиотеки кросс-платформенные,
рассчитаны на применение как в Windows, так и в Linux.

Исходной основой послужил код из репозитория https://github.com/cgommel/sdrsharp,
переработанный и дополненный.

## Состав решения

| Проект | Назначение | Версия |
|---|---|---|
| `SDRNet.Radio` | Базовая библиотека: квадратурные отсчёты, фильтры, преобразование частоты, детекторы, устройства звукового ввода и вывода | 1.0.4 |
| `SDRNet.RTLSDR` | Приёмное устройство RTL-SDR | 1.0.5 |
| `SDRNet.RTLTCP` | Приём сигнала по сети от сервера `rtl_tcp` | 1.0.4 |
| `SDRNet.HackRfOne` | Устройство HackRF One: приём и передача сигнала | 1.0.4 |

Библиотеки взаимодействия с устройствами (`SDRNet.RTLSDR`, `SDRNet.RTLTCP`,
`SDRNet.HackRfOne`) используют базовую библиотеку `SDRNet.Radio` и реализуют общий
интерфейс `IFrontendController`, что позволяет подключать разные устройства единообразно.

## Возможности

**Приём.** Общий для всех устройств интерфейс `IFrontendController`: открытие и закрытие
устройства, настройка частоты и частоты дискретизации, поток отсчётов через событие
`SamplesAvailable`.

**Передача.** Реализована для HackRF One через интерфейс `ITransmitter`: запуск и останов
передачи, ступень усиления передающего тракта, поток отсчётов через событие
`TxSamplesNeeded`. Устройство полудуплексное: одновременные приём и передача невозможны.

**Формирование сигналов.** Класс `SignalGenerator` формирует гармонические колебания,
шум, обеспечивает сдвиг спектра и сглаживание фронтов. Класс `SampleConverter`
выполняет преобразования отсчётов между форматами устройства (знаковые восьмиразрядные),
звуковых карт (шестнадцатиразрядные) и комплексными отсчётами.

## Использование

### Приём сигнала (RTL-SDR)

```csharp
using SDRNet.RTLSDR;

using var io = new RtlSdrIO();
io.Open();
io.Samplerate = 2_048_000;
io.Frequency = 100_000_000;

var device = io.Device!;
device.UseTunerAGC = false;
device.Gain = 200;                       // ступень усиления в десятых долях дБ

io.SamplesAvailable += (sender, buffer, length) =>
{
    // buffer — указатель на массив из length комплексных отсчётов
};

io.Start();
```

### Приём сигнала (HackRF One)

```csharp
using SDRNet.HackRfOne;

using var io = new HackRFIO();
io.Open();
io.Samplerate = 2_000_000;
io.Frequency = 433_920_000;
io.Start();
```

### Передача сигнала (HackRF One)

```csharp
using SDRNet.HackRfOne;

using var io = new HackRFIO();
io.Open();
io.Samplerate = 2_000_000;
io.Frequency = 433_920_000;
io.TxVGAGain = 20;                       // усиление передающего тракта, 0–47 дБ
io.EnableAmp = false;                    // встроенный усилитель: включать только с нагрузкой

var phase = 0.0;
io.TxSamplesNeeded += (sender, e) =>
    phase = SignalGenerator.GenerateTone(
        e.Buffer, e.Length, io.Samplerate, 1000.0, 0.5f, phase);

io.StartTransmit();
// передача продолжается до вызова StopTransmit
io.StopTransmit();
```

Перед запуском передачи необходимо остановить приём: устройство полудуплексное, попытка
совместить оба режима приводит к исключению.

## Нативные библиотеки

Для работы требуются внешние нативные модули:

- `SDRNet.RTLSDR` — `librtlsdr` и `libusb-1.0`;
- `SDRNet.HackRfOne` — `libhackrf` и `libusb-1.0`.

Готовые модули для 64-разрядной версии Windows находятся в каталоге `Libs/Win_x64`.
Их необходимо либо установить в систему (вместе с драйверами устройств), либо поместить
рядом с исполняемым файлом приложения. Пакеты NuGet нативные модули не включают.
